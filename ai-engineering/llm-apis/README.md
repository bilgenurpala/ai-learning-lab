## 🧮 Theoretical & Mathematical Foundations

### 1. Token Probability & Temperature Scaling
LLMs output predictions as raw logit values $z_i$ for each token in the vocabulary. To transform these logits into probabilities, we apply the Softmax function.
To control the model's creativity or determinism, we introduce a **Temperature ($T$)** scaling parameter:
$$P(w_i \mid w_{<i}) = \text{Softmax}\left(\frac{z_i}{T}\right) = \frac{e^{z_i / T}}{\sum_{j=1}^C e^{z_j / T}}$$
Where $C$ is the vocabulary size.
*   **Low Temperature ($T \to 0$):** The probability distribution concentrates heavily on the highest logit. The model becomes deterministic (approaching Argmax selection).
*   **Standard Temperature ($T = 1$):** Logits are unmodified. Token selection matches the default model probabilities.
*   **High Temperature ($T > 1$):** Logits are scaled down, flattening the probability distribution. This increases randomness and creativity.

---

### 2. Token-to-Word Estimation
Large Language Models process text in sub-word units called tokens.
$$\text{Estimated Tokens} \approx \text{Word Count} \times 1.33$$
$$\text{Estimated Words} \approx \text{Token Count} \times 0.75$$
For safety and cost budgeting, we calculate input/output token limits using:
$$\text{Total Tokens} = \text{Input Tokens} + \text{Output Tokens} \le \text{Max Context Window}$$

## 📔 Chapter-by-Chapter Course Summaries

### Chapter 1: Introduction to the OpenAI API and ChatGPT
Covers client initialization and the core structure of the Chat Completions API.
*   **API Client Setup:**
    ```python
    from openai import OpenAI
    client = OpenAI(api_key="your-api-key-here")
    ```
*   **Multi-Role Completions:**
    The API uses three roles to direct context:
    1.  `system`: Sets the persona, guardrails, and instructions.
    2.  `user`: The prompt or query from the end user.
    3.  `assistant`: The historical response generated by the model.
*   **Code Example:**
    ```python
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[
            {"role": "system", "content": "You are a helpful data science assistant."},
            {"role": "user", "content": "Explain what a standard scaler does."}
        ],
        temperature=0.5,
        max_tokens=150
    )
    print(response.choices[0].message.content)
    ```

---

### Chapter 2: Text Generation and Structuring Output
Focuses on controlling model outputs and forcing structured formats.
*   **JSON Mode Enforcements:**
    By telling the model to output JSON in the system message and setting `response_format={"type": "json_object"}`, we guarantee a parseable JSON response.
*   **Code Example:**
    ```python
    import json

    response = client.chat.completions.create(
        model="gpt-4o",
        response_format={"type": "json_object"},
        messages=[
            {"role": "system", "content": "You are a database designer. Output a JSON object containing a list of 'tables' with 'columns'."},
            {"role": "user", "content": "Create a schema for a school enrollment database."}
        ]
    )
    
    schema = json.loads(response.choices[0].message.content)
    print(json.dumps(schema, indent=2))
    ```

### Chapter 3: Moderation and Safe Text Generation
Details defensive prompt engineering and scanning inputs/outputs for violations.
*   **OpenAI Moderation API:**
    Evaluates inputs across categories like hate speech, harassment, self-harm, sexual content, and violence.
*   **Code Example:**
    ```python
    moderation_response = client.moderations.create(
        input="I hate everyone and want to destroy their networks."
    )
    results = moderation_response.results[0]
    
    if results.flagged:
        print("Blocked: Input violates safety policies.")
        for category, flagged in results.categories.items():
            if flagged:
                print(f"- Violated Category: {category}")
    ```

---

### Chapter 4: Multi-Turn Conversation History
To build conversational memory, we maintain a history list of message objects, appending user inputs and assistant outputs sequentially.
*   **Code Example:**
    ```python
    chat_history = [
        {"role": "system", "content": "You are a friendly AI tutor."}
    ]

    while True:
        user_input = input("You: ")
        if user_input.lower() == "quit":
            break
            
        chat_history.append({"role": "user", "content": user_input})
        
        response = client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=chat_history
        )
        
        reply = response.choices[0].message.content
        print(f"AI: {reply}")
        chat_history.append({"role": "assistant", "content": reply})
    ```
