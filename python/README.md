## Notebooks

### python_basics.ipynb

Built a solid Python foundation topic by topic. Each concept is reinforced with a mini project or exercise.

Topics covered:
- Variables & data types — integers, floats, strings, booleans, type conversion
- Control flow — `if / elif / else`
- Lists — indexing, `random.choice()`, `random.shuffle()`
- Loops — `for`, `while`, `range()`, `enumerate()`
- Functions — `def`, `return`, parameters, scope
- Dictionaries — key-value pairs, `.items()`, `max(dict, key=dict.get)`
- Function parameters — default parameters, `%` modulo operator, `ord()`
- Function outputs — storing functions in dictionaries, dynamic calls
- Scope — local vs global, passing data via parameters
- Debugging — common bugs, `str()` conversions, `==` vs `=`
- Modules — `import`, multi-file structure

Projects built: Hangman, Blackjack, Caesar Cipher, Calculator, Password Generator, Silent Auction, Higher or Lower, Number Guessing Game

### python_intermediate.ipynb

Covers the Python ecosystem in depth — how packages work, how to write robust functions, and how to handle errors properly.

**Chapter 1 — The Python Ecosystem**
- Built-in functions — `max()`, `min()`, `sum()`, `round()`, `len()`, `sorted()`
- Modules — `os` (working directory, environment), `string` (ascii, digits, punctuation)
- Packages — `pip` install workflow, importing with aliases, intro to pandas DataFrames, reading CSV files

**Chapter 2 — Working with Functions**
- Custom functions — when and why to write them
- Positional and keyword arguments
- Default arguments
- Docstrings — single-line, multi-line, `Args` / `Returns` format
- Arbitrary positional arguments (`*args`)
- Arbitrary keyword arguments (`**kwargs`)

**Chapter 3 — Lambda Functions & Error Handling**
- Lambda functions — syntax, using with `map()` and `filter()`
- Common errors — `TypeError`, `ValueError`
- `try / except` — preventing crashes
- `raise` — intentionally triggering errors
- Difference between `try/except` and `raise`
